# SQL scripts

Keep schema and query SQL versioned in this directory:

- `001_schema.sql`: tables, keys, and integrity constraints.
- `002_views.sql`: shared views and aggregate queries.
- `003_seed.sql`: demo data for local runs and tests.
- `migrations/`: later changes to an already-created schema.

The scripts are intentionally not populated yet; align them with the team's
final schema before loading them into MySQL.
